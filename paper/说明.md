## 源稿中的两种排版标记

为了自动排版，Markdown 里用了两个自定义标记，转换时会自动处理，**Word 成品里看不到它们**：

| 标记 | 含义 | 排版结果 |
|---|---|---|
| `{c:1,2}` | 引用标注 | 上标 `[1,2]` |
| `@@EQ@@ $...$` | 独立公式 | 居中公式，`_{x}` 变下标、`^{x}` 变上标 |

所以如果你直接读 `.md` 看到这些符号，不用惊讶——它们是给排版程序看的。

## 如何重新生成 Word

```bash
cd virtual-cell-lab
cp paper/论文草稿.md output/vcl-paper-20261122/stage1/final_draft.md
python output/vcl-paper-20261122/working/md2html.py \
  output/vcl-paper-20261122/stage1/final_draft.md \
  output/vcl-paper-20261122/stage2/formatted-paper.html

# 标记化（保护上下标）→ 转换 → 还原上下标
python output/vcl-paper-20261122/working/mark_for_docx.py \
  output/vcl-paper-20261122/stage2/formatted-paper.html \
  output/vcl-paper-20261122/stage2/_for-docx.html

python <workbuddy-docx>/skills/html-to-doc/scripts/convert_doc.py \
  --html output/vcl-paper-20261122/stage2/_for-docx.html \
  --output output/vcl-paper-20261122/stage3/<文件名>.docx \
  --require-page-furniture --require-toc

python output/vcl-paper-20261122/working/restore_scripts.py \
  output/vcl-paper-20261122/stage3/<文件名>.docx
```
