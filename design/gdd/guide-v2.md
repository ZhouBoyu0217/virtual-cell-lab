> 本文档是 `onboarding-design.md` §6「L1 前 3 步逐字脚本」的**升级版**，不推翻三层引导架构（Tier 1/2/3、`GS` 状态机、`LAYERS` 归层、`setTier` 唯一跃迁入口全部保留）。

## 0. 一句话结论

**从「教你点哪里」升级为「让你在 30 秒内自己发现：你动因子 → 培养皿回应 → 坏细胞比例是判据」。**

步数：**3 步 → 4 步**（含 1 次步内确认刷新，不是第 5 步）。
原则：**弱引导 ≠ 少引导，而是把力气从"牵着走"移到"建立心智模型"。** 全程无遮罩、无强制点击、每条 ≤ 2 句、玩家可随时无视。

## 1. 三个缺陷 → 四个改造要求的映射

| # | 已诊断缺陷（有证据） | 对应改造要求 | v2 落点 |
|---|---|---|---|

### 关于缺陷 3 的三个"玩家不知道"，v2 逐一补齐

|---|---|---|

## 2. 步骤数建议：3 → 4 步

### 建议：**4 步**（索引 0–3）

**理由：**

1. **上了限**。4 步是"讲清机制"所需的最小集合 —— 每一部分各占一步，无法再合并：
   - Step 0 = 敌人是谁 + 为什么要担心（机制）
   - Step 1 = 唯一的杠杆为什么有用（因果）
   - Step 2 = 亲手验证因果（对照观察）
   - Step 3 = 把"我发现的"固化成"判据"，并交还主动权（收束）
2. **不能再多**。任何第 5 步（例如单开一步讲"危险度""时长")都会违反要求 4（弱引导克制），并把玩家重新推回"被牵着走"。判据与时长概念刻意留给 Tier 2 教学（`onboarding-design.md` §4.5.3 已定调：时长延后到 L2）。
3. **不能回到 3 步**。若把"对照观察"和"收束"合并回一步，玩家就没有独立的"我发现了"时刻 —— 那正是缺陷 3 的根因。

### 为什么不干脆只做 2 步（更克制）

弱引导的正确做法不是"少说"，而是"把每一步说到能建立模型"。2 步无法在"讲机制"与"让玩家自己发现"之间各留空间 —— 会退回"被告知"。4 步是"克制"与"建模型"的平衡点。

### Step 0 · 「这是盘什么」— 建立敌人与机制

| 项 | 内容 |
|---|---|
| **目的** | 回答"为什么这盘细胞危险" —— 不是"这里有一盘细胞"，而是"坏细胞会越裂越多" |
| **触发条件** | `boot()` 末尾（`index.html:4100`）：`GS.tier === 1 && GS.missionsWon === 0 && GS.step === 0`（**沿用现有触发，不改**） |
| **气泡 `#hint2`** | `这盘细胞里混进了坏细胞 —— 点 ▶ 让时间跑起来，看着它们分裂。` |
| **旁白 `#evt`** | `欢迎来到虚拟细胞实验室。坏细胞会不停分裂、挤占别的细胞的地盘 —— 它们越分裂越多，这盘细胞就越危险。` |
| **视觉引导** | ① `.shell.focusing` 生效（压暗右栏，唯一亮块 = 培养皿，沿用现有 CSS `index.html:310`）② `#btnPlay` 呼吸脉冲（沿用现有 `focusPulse`，`index.html:328`）③ 坏细胞轻微高亮：调 `highlightTumors()`（`index.html:870`） |
| **玩家动作** | 点击 `#btnPlay` |
| **状态变更** | `GS.step = 1` |

**对比现状的改进**：现文案已提"抢地盘"（`index.html:884`），v2 补上**归因句**"越分裂越多 → 越危险"，让玩家在动手前先建立"数量 = 危险"的直觉，为 Step 2 的"看比例"埋线。

### Step 1 · 「唯一的杠杆」— 讲清免疫为什么有用（要求 1）

| 项 | 内容 |
|---|---|
| **目的** | **先讲机制，再给动作**（这正是要求 1 的示范） |
| **触发条件** | `#btnPlay` 点击且 `playing` 变 true（`index.html:3898`，**沿用现有触发，不改**）<br>· 追加一条健壮性判断：若此刻 `E.immune >= 60`（玩家提前拖过），立即续推 `runGuideStep(2)`，避免卡在 Step 1 |
| **气泡 `#hint2`** | `盘子里有保安（免疫细胞）—— 免疫兵力推高，它们就会去追杀坏细胞。试试推到 60。` |
| **旁白 `#evt`** | `看，颜色最深的这几个就是坏细胞 —— 它们正在偷偷分裂。记住它们的样子。` |
| **视觉引导** | ① `highlightTumors()`（红色描边 + `seedPulse` 光环，沿用）② **新增** `highlightLever('immune')`：给免疫滑块行（`[data-sl="immune"]`）一次脉冲高亮，把视线引到"唯一杠杆"上 |
| **玩家动作** | 拖动免疫滑块至 ≥ 60 |
| **状态变更** | `GS.sliderTouched.immune = 1; GS.step = 2` |

**对比现状的改进**：
- 现状（`index.html:889`）：「把「免疫兵力」拖到 60 以上试试 👉」—— 只有动作，没有因果。
- v2：「**盘子里有保安 —— 推高它们就会去追杀坏细胞**。试试推到 60。」—— 先给机制，再给动作。玩家推滑块时**知道自己在干什么**。

### Step 2 · 「对照观察点」— 让玩家自己发现因果（要求 2 · 核心新增）

| 项 | 内容 |
|---|---|
| **目的** | 把缺陷 1 的"干等"改造成**带观察任务的实验**，制造"我发现了"的时刻 |
| **触发条件** | 免疫滑块输入且 `E.immune >= 60`（`index.html:1131`，**沿用现有触发，索引不变**）<br>· 进入本步时记录基线：`GS.step2Baseline = M.tumorPct` |
| **气泡 `#hint2`** | `绿色那些是保安，正在贴上去 —— 盯住「坏细胞比例」这个数，看它降不降。` |
| **旁白 `#evt`** | `别动别的因子，只看这一件事：保安咬上坏细胞之后，比例会怎么变？盯着看 10 秒。` |
| **视觉引导** | ① 移除 `.shell.focusing`（右栏放开，让指标卡读得到）② **新增** `highlightImmuneCells()`：给所有 `type === 'immune'` 的细胞加 `seedPulse`（镜像 `highlightTumors()` 的写法）③ **新增** `highlightMetric('mTumorCard')`：给「坏细胞比例」指标卡一次脉冲高亮，明确告诉玩家"盯这个数" |
| **玩家动作** | 观察（不动别的因子） |
| **状态变更** | `GS.step = 2`（进入时记 `step2Baseline`） |

#### Step 2 · 步内确认刷新（不是第 5 步）

| 项 | 内容 |
|---|---|
| **目的** | 让 Step 2 不"过时" —— 玩家真的看到比例下降后，立刻**归因**，把"数值变化"变成"我干的" |
| **触发条件** | `GS.step === 2 && !GS.step2Confirm && (GS.step2Baseline - M.tumorPct) >= 3`（比例自进入本步起下降 ≥ 3 个百分点）<br>· 兜底：进入 Step 2 后 ≥ 8 秒仍未达标，且比例有下降（≥ 1 点）也触发，避免卡死 |
| **气泡 `#hint2`（替换）** | `比例在跌 —— 这一下是你推的免疫干的。保持住，把这道实验打完，右侧会解锁更多因子。` |
| **旁白 `#evt`（替换）** | `看到了吗？你动的因子，培养皿会立刻回应，比例就是它的回答 —— 这就是这盘细胞的读法。` |
| **视觉引导** | 保留 `highlightMetric('mTumorCard')` 的余韵；不再重复高亮免疫细胞 |
| **状态变更** | `GS.step2Confirm = true`（**不推进 `GS.step`** —— 它不是独立步骤，只是本步的确认态） |

**对比现状的改进**：
- 现状（`index.html:892`）：「什么都不用做，让它跑一会儿」—— 反高潮，玩家从参与者变旁观者。
- v2：「**盯住这个数，看它降不降**」→ 观察成功后「**比例在跌 —— 是你推的免疫干的**」—— 玩家自己看出来的因果，引导只负责确认。这正是"让玩家以为是自己发现的"。

### Step 3 · 「收束」— 交还主动权，自然交接 Tier 2（要求 3）

| 项 | 内容 |
|---|---|
| **目的** | ① 把"我发现的"固化成可复用的**判据**；② 不停下来，直接给出**下一个开放动作**（指向 Tier 2 新解锁的因子） |
| **触发条件** | `setTier(n)` 内（`index.html:750`），当 `n >= 2 && GS.step < 3 && !GS.expert` → 调 `runGuideStep(3)`<br>· 覆盖两条通往 Tier 2 的路径：**赢下第一题**（`finishMission` → `checkTierUnlock`，`index.html:1028`）与**第二条路**（反复拖同一根 ≥5 次 且 回合 ≥60，`index.html:773`）<br>· 兜底：若玩家用专家模式进入（`GS.expert`），**不播**收束（专家模式本就是逃生通道） |
| **气泡 `#hint2`** | `你已经会了：推免疫 → 坏细胞比例下降。接下来试试右侧其他因子，看它们各有什么效果。` |
| **旁白 `#evt`** | `✓ 你赢下了第一局 —— 免疫压力真的把坏细胞压住了。记住这套读法：你动因子，看比例。` |
| **视觉引导** | ① 高亮 `#envCard` 里新解锁的因子行（`[data-sl="nutrient"]` / `[data-sl="oxygen"]`，脉冲一次）② 新面板入场沿用现有 `reveal-card`（`index.html:843-851`）③ `#hint2` 已随 `body.tier-2` 回到右下常态位置，作为**持续可见的开放任务**留在屏上 |
| **玩家动作** | 自由探索（无强制） |
| **状态变更** | `GS.step = 3`（引导序列终结，`GS` 完整） |

#### ⚠️ 文案冲突协调（必须由工程侧处理后才能上线）

**处理方案（二选一，推荐 B）：**

- **B（推荐）**：Step 3 的旁白**就是**首胜台词的升级版（见上方文案），工程侧把 `index.html:1019` 与 `1030-1032` 两处替换为 Step 3 旁白文本，Step 3 只负责发 `#hint2` 气泡 + 高亮因子行，**不再单独发 `#evt`**，从根上消除覆盖。

## 6. 收束 → Tier 2 交接设计

**要点：收束不制造"结束感"，而制造"解锁感"。**

1. **时点同构**：Step 3 在 `setTier(2)` 触发 —— 玩家赢下第一局的**同一刻**，右侧解锁养分/含氧量/曲线/局势。收束台词落在"新东西刚出现"的瞬间，天然把"完成"读成"打开"。
2. **判据沉淀**：气泡把三步操作压缩成一句可复用的公式 ——「**推免疫 → 坏细胞比例下降**」。这是玩家带得走的心智模型，也是后续 5 道实验的通用读法（每题都是"动因子 → 看比例/危险度"）。
3. **开放动作**：气泡末句指向**新解锁的因子**（而非"再来一题"）。玩家此刻的默认行为 = 拖一拖刚出现的养分/含氧量滑块，正好落在 `checkTierUnlock` 的 T2→T3 路径（`distinctSliders() >= 5`，`index.html:779`）上 —— **引导的收束即下一个解锁条件的起点**，形成"探索 → 解锁 → 再探索"的自持循环。
4. **弱引导的克制**：Step 3 之后**不再有编号步骤**。气泡作为一条常驻的开放提议留在屏上，玩家可无视（去点细胞、看曲线、换实验）。引导至此**主动退场**。

## 7. 边界情况与健壮性

| # | 情况 | 处理 |
|---|---|---|
| 1 | 玩家在 Step 0 就先拖免疫到 100，再点播放 | M2 的追加判断：`runGuideStep(1)` 后立即检测 `E.immune >= 60` → 续推 Step 2；进入时记录 `step2Baseline`（此时比例高，观察落差更明显） |
| 2 | 玩家在 Step 2 一直不打完实验 | Step 2 不会卡死：气泡是"观察任务"而非"等待指令"；且有 §3 的 8 秒兜底确认。玩家可继续拖因子 / 换题，引导不阻塞 |
| 3 | 玩家走"第二条路"（反复拖同一根 ≥5 次 且 回合 ≥60）升 Tier 2 | M5（`setTier` 内）保证收束照样播 —— 即使没赢下第一题，也能拿到心智模型总结 |

| 8 | `#hint2` 被画布点击覆写为「已选中 · 点击其他地方可换」（`index.html:3560`） | Tier 2 之后发生属正常（收束气泡已完成使命）；Tier 1 期间玩家不会点细胞（工具未解锁），无冲突 |
