## 0. 一句话结论

**当前画面「不高级」不是因为缺装饰，而是因为：① 灰色阶太挤（108 个色 token，相邻面差小到看不见）；② 边框在全页重复 9 次同一个值，失去层级信号；③ 强调绿用了 32 个近色 token，绿色到处"跳"；④ Tier 1 右栏 1045px 完全空置，构图被动。**

**高级感的公式 = 可辨的层次（ΔL\* ≥ 1.5）+ 克制的用色（绿只做焦点锚点）+ 统一的 4px 间距网格 + 主动设计的留白。** 本方案全部给出可粘贴 CSS 与实测 WCAG 对比度。

> **克制纪律**：用户说"高级"指向**留白节奏 + 克制用色 + 细腻层次 + 统一间距**，**不是加更多装饰**。本方案**零新增装饰元素**，只做"减"与"收"。

### 1.2 四个病灶（每条附实测数字）

**病灶 ① 灰色阶太挤 —— 相邻面差小于人眼可辨阈值**

光源板里 28 个近中性灰，实测 `L*` 值大量相邻差 ≤ 0.6（人眼可辨阈值约 `ΔL* ≥ 1.5`）：

| 相邻对 | ΔL\* | 可辨? |
|---|---|---|
| `#1b1e22` → `#1c1f23` | 0.5 | ✗ |
| `#1d1f24` → `#1f2227` | 1.4 | ✗（临界） |
| `#2a2e34` → `#2a2e35` | **0.0** | ✗（**完全相同**） |
| `#24272c` → `#242830` | 0.5 | ✗ |
| `#2c2f36` → `#2d3037` | 0.5 | ✗ |
| `#32353c` → `#33363d` | 0.5 | ✗ |

> **结论**：作者在"微调"时反复生成了肉眼不可辨的新色 —— 这不是细腻，是**噪声**。28 个灰阶里实际只有约 10 个能被看见。

**病灶 ② 边框重复 9 次，失去层级信号**

`.card{background:#1a1c20;border:1px solid #282b31}` —— 旧边框 `#282b31` 对卡面的**可见度仅 1.20**，且**在 9 张卡上等值重复**。结果是"卡片墙"：每张卡的边界都存在，但没有一张卡说"先看我"。

- 现状实测：`#282b31` on `#1a1c20` = **1.20**
- 林绘澄 v3.1 已把 W2 边框改为 `#2a2e35`（1.25）/ W3 `#1f2227`（1.12）—— 方向正确，但**仍然全部低于可辨阈值**，且 `#2a2e35` 与旧值 `#282b31` 几乎无差（ΔL\* 0.0~1.3）。

**病灶 ③ 强调绿 32 个 token，绿色到处"跳"**

| 绿系 token | 用途 |
|---|---|
| `#7ddba8` ×4 | 强调绿（轨道/进度条/徽记） |
| `#e8fbf1` `#dcf5e8` `#cfe8d9` `#c9f0da` | 四种"近白绿"文字色 |
| `#3c7a5c` `#3f7d5f` `#2f5241` `#2c5b45` `#2e965c` `#2f7d5c` `#2f6b4f` `#37795a` `#3e8a66` `#3d7a5c` `#4a8a6b` `#3f7a5e` `#2c5b40` | 13 种深绿（按钮/边框/渐变） |
| `#1c2b23` `#1e3d2f` `#234030` `#243622` `#4c6f33` | 5 种绿底 |
| `#9fe0bb` `#8fd6b0` `#5fa87d` `#8fb8a2` |

> **用户感受"绿色跳"的根因**：Tier 1 首屏同时存在**整条高饱和绿轨道**（`#7ddba8`，对比 10.21）+ 绿渐变任务卡 + 绿边框 + **绿色脉冲发光**（`0 0 22px rgba(125,219,168,.14)` + `scale(1.012)`）。三处绿色同框争抢，反而**没有一个成为焦点**。

**病灶 ④ Tier 1 右栏 1045px 空置 —— 被动留空 ≠ 高级**

留白要"高级"，前提是**被设计过**（有画框感、有对齐关系、有节奏）。当前右栏是"内容没排满所以空着"，不是"故意留白"——视觉上读作**未完成**，而不是**克制**。

### 1.3 红线遵守（本方案零触碰）

## 2. 配色体系复核与优化（逐项判断 + 实测对比度）

### 2.1 表面阶梯：从"挤成一团"到"三阶可辨"

**问题**：现状页底 `#131417` → W3 `#16181b` → W2 `#1a1c20`，相邻 ΔL\* 只有 1.8 / 2.1，且叠加 `brightness(.78)` 后进一步塌缩。

**方案**：把页底再沉半档，拉开与卡面的距离，让卡"浮"起来。

| 用途 | 现状 | **新值** | L\* | ΔL\* | 说明 |
|---|---|---|---|---|---|
| 页底 | `#131417` | **`#111214`** | 5.4 | — | 再沉半档，给卡面腾出"浮起"空间 |
| W3 卡面 | `#16181b` | **`#15171a`** | 7.6 | +2.2（vs 页底） | |
| W2 卡面 | `#1a1c20` | **`#181a1e`** | 9.2 | +1.6（vs W3） | |
| W2 卡内嵌块 | `#212429` | **`#1f2228`** | 13.1 | +3.9 | 嵌入感 |
| W3 卡内嵌块 | `#1b1e22` | **`#1b1e22`** | 11.1 | 保留 | |
| 皿底色 | `#0d0e10` | **`#0d0e10`** 🚫 | 3.9 | 不动 | **红线** |

> **验收**：W2 vs W3 `ΔL* = 1.6 ≥ 1.5` ✓ 可辨；W3 vs 页底 `ΔL* = 2.2` ✓。**这是"卡片墙"消解的关键** —— 现在每层都真的能被看见。
> 注：W2-W3 只留 **1.6** 而非拉大，是**刻意的克制** —— 层级主要靠**边框 + 文字档位**合力，面差只做轻微托底（延续 v3.1 §8.1 的判断）。

### 2.2 边框：从"全页同一个值"到"三层信号"

**问题**：`#282b31` 重复 9 次；新板 `#2a2e35` 仍不可辨（1.25）。

**方案**：W1 边框给出明确的"重点信号"，W2/W3 收到刚好可辨的下限，并给所有卡加 **1px 内高光**营造"嵌入感"。

| 层 | 现状 | **新值** | 对卡面可见度 | 说明 |
|---|---|---|---|---|
| **W1（任务卡）** | `#3f7d5f` (3.58) | **`#3a7055`** | **3.01** | 绿边略收，配合内高光 |
| W2 | `#2a2e35` (1.25) | **`#272b32`** | 1.23 | 收到刚好可辨边界 |
| W3 | `#1f2227` (1.12) | **`#1e2126`** | 1.11 | 近乎隐形 |
| 内高光（新增，全卡） | — | `inset 0 1px 0 rgba(255,255,255,.028)` | — | **"嵌入感"来源** |

> **关键手法：1px `inset` 内高光** —— 这是 Vercel / Linear 暗色卡的"高级"秘诀。它不改变边框色，只在卡顶内侧加一道极淡的白色高光，让卡片从"平面色块"变成"有厚度的面板"。
> 强度 **α 0.028**（W2）/ **0.020**（W3）—— 实测在 `#181a1e` 上等效 `#212328`，几乎看不见但**能感觉到**。**切忌超过 0.04**，否则变"玻璃反光"的廉价感。

```css
/* ---- 卡片嵌入感（可直接粘贴）---- */
.card{
  background:var(--w2-face); border:1px solid var(--w2-edge); border-radius:10px;
  box-shadow: inset 0 1px 0 rgba(255,255,255,.028), 0 1px 2px rgba(0,0,0,.22);
}
.card.w-panel{
  background:var(--w3-face); border-color:var(--w3-edge);
  box-shadow: inset 0 1px 0 rgba(255,255,255,.020);
}
```

### 2.3 文字三阶：从"卡在最坏中间地带"到"每档都合规"

**问题**：现状弱化色 `#6f727a` 在卡面上仅 **3.55（不过 AA）**，却用于大量说明文字（`.muted` / `.hint` / `.m .k` / `.preset span` / `.m-name em`）。这正是 v3.1 §1.2 病灶 B 指出的"既不够弱到退后，也不够亮到可读"。

| 角色 | 现状 | 对比度 | **新值** | 新对比度 | 用途 |
|---|---|---|---|---|---|
| 主文字 | `#e6e6ea` | 13.71 ✓ | **`#eceef2`** | **15.00 ✓** | 标题/正文/数字 |
| 次要 | `#9295a0` | 5.71 ✓ | **`#9ba0ab`** | **6.65 ✓** | 说明文字、标签 |
| W3 信息文字 | `#82858f` | 4.83 ✓ | **`#7f838d`** | **4.73 ✓** | W3 卡内可读文字 |
| 装饰专用 | `#6f727a` | **3.55 ✗** | **`#6a6d75`** | 3.37（**仅装饰**） | 图标/分隔线，**不承载信息** |

> **处置原则**：把 `#6f727a` 从"信息文字"降级为"装饰专用"，凡是**需要被读**的说明文字一律提到 `#7f838d`（4.73 ✓）或 `#9ba0ab`（6.65 ✓）。**这是本方案唯一"必须改"的合规修正。**

### 2.4 强调绿：从 32 个 token 收敛到 3 个角色

**判断**：**现有绿色确实用得过多、过"跳"。** 首屏同框出现"整条高饱和绿轨道 + 绿渐变卡 + 绿边框 + 绿脉冲发光"四处绿色，反而互相削弱。

**方案：绿只保留三档角色，其余全部中性化。**

| 角色 | 色值 | 对卡面对比度 | 变化 |
|---|---|---|---|
| **① 焦点绿（唯一高饱和）** | `#7ddba8` | 10.21 ✓ | **保留**，但**只用于**任务卡渐变 + `mile.got` + 徽记文字 |
| **② 深绿（按钮/选中）** | 现状 13 种 → **3 种**：`#2c6349` / `#274f3d` / `#3a7055` | 2.48 / 1.88 / 3.01 | 收敛，明度统一 |
| **③ 近白绿文字** | 现状 4 种 → **1 种**：`#e8fbf1` | 6.53 ✓ | 只保留一个 |

> **实测校验（收敛后仍全部合规）**：
> - 主按钮 `#e8fbf1` on `#2c6349` = **6.53 ✓**
> - 选中态 `#d8f0e4` on `#274f3d` = **7.70 ✓**
> - 强调绿 `#7ddba8` on 任务卡绿端 `#1c2b23` = **8.86 ✓**

```css
/* ---- 绿色收敛（可直接粘贴）---- */
button.pri{ background:#2c6349; border-color:#3a7d5c; color:#e8fbf1; }
button.on{ background:#274f3d; border-color:#376b52; color:#d8f0e4; }
```

### 2.5 唯一杠杆：绿色从"整条填满"到"低饱和轨道 + 高亮拇指"

**问题（实测）**：`body.tier-1 .lever input[type=range]{background:#7ddba8}` —— **整条轨道铺满高饱和绿**（对比 10.21），是 Tier 1 右栏最"跳"的元素，直接与培养皿争焦。

**方案**：轨道降为低饱和暗绿，把"强调"集中到**拇指**（尺寸 + 光环双通道）。视觉上仍是"唯一有颜色的控件"，但不再刺眼。

| 元素 | 现状 | **新值** | 实测 |
|---|---|---|---|
| 普通轨道 | `#31343b` (h4px) | **`#2b2f37`** (h**3px**) | 更细更沉 |
| 杠杆轨道（Tier 1） | **`#7ddba8`（整条亮绿）** | **`#3a4d43`**（低饱和暗绿） | 1.93（不刺眼） |
| 杠杆拇指 | 19px `#e8fbf1` + 绿光环 | **16px** `#eef7f1` + `0 0 0 2px rgba(125,219,168,.30)` | 15.94 ✓ |

> **逻辑**：不靠"更亮"而靠"**唯一有饱和度**"来标识杠杆 —— 一级视觉锚点应该是**培养皿**，杠杆只需要"和别的不一样"。
> ⚠️ 轨道高度 4px → **3px**：更细的轨道是"精密仪器"的视觉语言（Linear 的滑块也是细轨道）。

### 2.6 任务卡：从"过曝发光"到"克制内描边"

**问题（实测）**：任务卡当前 `box-shadow: 0 0 22px rgba(125,219,168,.14)` + `transform: scale(1.012)`。`scale` 非整数倍会导致**文字重绘模糊**（不是 1px 对齐），在大屏上肉眼可见。

**方案**：去掉发光与缩放，改为**内高光 + 细绿描边 + 落地阴影**三重克制信号。

```css
/* ---- 任务卡（可直接粘贴）---- */
#missionCard.w-mission{
  border-color:#38684f;
  transform: none;                                  /* 去掉 1.012 缩放，消除模糊 */
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.05),            /* 内高光：厚度感 */
    0 0 0 1px rgba(77,154,114,.22),                 /* 细绿描边：焦点信号 */
    0 8px 22px rgba(0,0,0,.34);                     /* 落地阴影：浮起 */
}
```

> **实测**：任务卡边框 `#38684f` on 卡面 `#181a1e` = 2.71。**低于 v3.1 的 3.20，是有意的** —— 因为新增了 `inset` 内高光与 `0 0 0 1px` 细描边共 3 层信号，不需要单靠边框色"喊"。若不接受，可用 `#3a7055`（3.01）折中。

## 3. 视觉简洁度优化

### 3.1 该"更轻"的元素（字号/字重/透明度）

| 元素 | 现状 | 建议 | 理由 |
|---|---|---|---|
| 指标数字 `.m .v` | `21px / 500` | **`20px / 450`** | 数字太大太粗 → 抢焦 |
| 卡片标题 `.ctitle` | `13px / 500` | **`12.5px / 500` + `letter-spacing:.2px`** | 统一全页标题节奏 |
| 弱化文字 | `11px #6f727a`(3.55✗) | **`11px #7f838d`**(4.73✓) | 合规 + 更清晰 |
| 滑块轨道 | `h4px #31343b` | **`h3px #2b2f37`** | 更细 = 更精密 |
| 卡片圆角 | `12px` | **`10px`** | 收紧一档，暗色 UI 更"利落" |
| 卡内嵌块圆角 | `9px` | **`8px`** | 与 `--sp` 网格对齐 |

### 3.2 统一 4px 基准网格（实测哪些越界）

**现状间距抽查**：`padding:14px` / `gap:14px` / `gap:12px` / `padding:9px` / `gap:7px` / `padding:5px` / `margin-bottom:11px` —— **14 / 11 / 9 / 7 / 5 全部不在 4px 网格内**。

| 现状值 | 网格内? | 建议 |
|---|---|---|
| `14px` | ✗ | **`16px`**（卡内距）/ **`12px`**（卡间距） |
| `11px` | ✗ | **`12px`**（标题下距） |

## 4. 「高级感」具体手法（5 条，每条可直接粘贴）

> 用户说"高级"指向 **留白节奏 + 克制用色 + 细腻层次 + 统一间距**，**不是加装饰**。以下 5 条全部是"减/收/调"，**零新增装饰元素**。

### 手法 1 —— 1px 内高光，制造"面板厚度感" ★核心

**这是暗色 UI "高级"的第一秘诀。** 平面色块看起来"平"且"廉"，加一道顶部内高光后立刻有"实体面板"的厚度。

```css
.card{ box-shadow: inset 0 1px 0 rgba(255,255,255,.028), 0 1px 2px rgba(0,0,0,.22); }
.card.w-panel{ box-shadow: inset 0 1px 0 rgba(255,255,255,.020); }
```

- 强度 **α 0.028**（W2）/ **0.020**（W3）—— 极性克制，**切忌 > 0.04**
- 第二层 `0 1px 2px rgba(0,0,0,.22)` 是极浅落地阴影，让卡片"离"页面 1px
- 参考方向：Vercel / Linear 暗色卡

### 手法 2 —— 留白节奏：用间距分层，不用分割线

**问题**：现状 `.m-tip{padding-top:9px;border-top:1px solid #24272c}` 等大量 1px 分割线，视觉上"到处都是线"。

**方案**：能靠**间距**分开的，就不要画线。保留的线一律降到"刚好可辨"。

```css
/* 卡内结构分隔：优先用间距 */
.m-tip{ margin-top:14px; padding-top:12px; border-top:1px solid var(--w2-edge); }
/* 卡与卡之间：只用 gap，绝不加分割线 */
```

> **原则**：**一屏内可见的分割线 ≤ 3 条**。分割线是"最后手段"，不是默认手段。

### 手法 3 —— 克制焦点高亮：焦点靠"对比"而非"更亮"

**问题**：现状靠"给焦点加发光 + 加缩放 + 加脉冲"三件套，结果焦点元素"过曝"。

**方案**：焦点的关键是**周围足够安静**。把非焦点"收"下去，焦点自然浮起 —— **不要给焦点加东西**。

```css
/* Tier 1：取消"整卡压暗"（现状会把文字压到 3.47，不过 AA） */
.shell.focusing .card{ filter:none; }
.shell.focusing .card.w-panel{ filter:brightness(.86) saturate(.9); }
body.tier-1 #envCard{ filter:none !important; }   /* 唯一杠杆卡保持满明度 */
```

> **实测修正**：现状 `.shell.focusing .card{filter:brightness(calc(var(--w-b)*.72))}` 会把次要文字压到 **3.47（不过 AA）**。改为 `brightness(.86)` 后，仅对 W3 面板生效，杠杆卡完全不压。

### 手法 4 —— 细腻过渡：统一缓动 + 克制时长

**问题**：现状缓动散乱（`.12s` / `.25s` / `.28s` / `.32s` / `.45s`），手感不统一。

**方案**：全部收敛到两个缓动 + 一组时长 token（延续 v3.1 §7 的缓动哲学）。

```css
:root{
  --e-out:cubic-bezier(.22,1,.36,1);     /* 进入：快起慢停 */
  --e-inout:cubic-bezier(.4,0,.2,1);     /* 氛围：对称 */
  --d-fast:140ms;   /* hover */
  --d-focus:320ms;  /* 焦点抬升 */
  --d-dim:600ms;    /* 压暗 */
}
button{ transition: background var(--d-fast) ease, border-color var(--d-fast) ease; }
.card{ transition: filter var(--d-dim) var(--e-inout), box-shadow var(--d-focus) var(--e-out); }
```

### 手法 5 —— 圆角与描边的"利落感"

**问题**：现状圆角族 `12/11/9/8/7/6/5/4px` 八档混杂，视觉上"圆角不齐"。

**方案**：收敛到 **3 档**（卡 / 嵌块 / 胶囊）。

```css
--r-card:10px;   /* 主卡 */
--r-inset:8px;   /* 卡内嵌块、按钮、输入 */
--r-pill:999px;  /* 徽记、胶囊 */
```

> **暗色 UI 的圆角应偏小**（10px 而非 12/16px）—— 大圆角在暗色下读作"柔和/可爱"，小圆角读作"精密/专业"。这是"科研基调"的选择。

## 5. Tier 1 首屏视觉建议（配合工程侧修空白）

> **背景**：实测右栏 h=118px，下方 **1045px 完全空置**。布局问题已派工程侧修。**从视觉角度，我给三条方案（按推荐度排序）**。

### 方案 A（推荐）—— 「单栏组合式」构图：把留白变成画框

**思路**：Tier 1 内容少，就不该用"两栏"这个为多内容设计的骨架。改为**居中单栏版心**（宽约 1000px），把任务卡与唯一杠杆**并排**，消除空轨。

布局顺序：
```
┌──────────────────────────────────┐
│  培养皿（全宽 960px）              │   ← 绝对主角，占首屏 65%
├────────────────┬─────────────────┤
│  任务卡（2.1fr） │ 唯一杠杆（1fr）   │   ← 并排，高度对齐
├────────────────┴─────────────────┤
│  指标 × N（全宽）                  │
├──────────────────────────────────┤
│  控制条 ▶ ⏸ 单步 重置 …           │
└──────────────────────────────────┘
        版心居中，两侧留白 = 画框
```

**实现（纯 CSS，零 DOM 改动，用 `display:contents` 拆栏）**：

```css
/* Tier 1 单栏组合式布局（可直接粘贴） */
body.tier-1 .shell{ max-width:1000px; padding:16px 20px 44px; }
body.tier-1 .grid{
  display:grid; grid-template-columns:minmax(0,1.35fr) minmax(0,1fr);
  gap:12px 16px; align-items:start;
}
body.tier-1 .colL,
body.tier-1 .colR{ display:contents; }          /* 拆封两栏，子元素直接参与外层 grid */

body.tier-1 .dishwrap{ grid-column:1/-1; order:1; }      /* 培养皿全宽 */
body.tier-1 #missionCard{ grid-column:1/2; order:2; height:100%;
  display:flex; flex-direction:column; }
body.tier-1 #missionCard .m-acts{ margin-top:auto; }
body.tier-1 #envCard{ grid-column:2/3; order:3; height:100%;
  display:flex; flex-direction:column; justify-content:center; }
body.tier-1 .metrics{ grid-column:1/-1; order:4; }
body.tier-1 #ctrlBar{ grid-column:1/-1; order:5; }
body.tier-1 .hud2{ display:none; }
```

**为什么它"高级"**：
1. **版心居中 + 两侧留白 = 画框** —— 留白从"未完成"变成"聚焦"。
2. **培养皿占首屏 65%**，成为无可争议的主角（延续 v3.1 "培养皿是唯一亮块"）。
3. **任务卡与杠杆并排 = 高度对齐** —— 消除"长短不齐"的草率感。
4. **零 reflow 风险**：`display:contents` 只改布局归属，Tier 切换时把 `.grid` 恢复 `flex` 即回原状。

> **实测（`_dev/art-AFTER-tier1.png`）**：版心 960px 居中，培养皿 h=811px，任务卡 542×167 与杠杆 402×167 **高度完全对齐**，指标与控制条全宽，**全页无空轨**，页面总高从 1267 → 1232px。

### 方案 B（保守）—— 保留两栏，右栏向下延伸

若工程侧坚持两栏：让 `.colR` 在 Tier 1 时**吸收左栏多余高度**，把 `#envCard` 与指标卡一起放进右栏下半部，消除"单卡悬顶"。

```css
body.tier-1 .colR{ justify-content:flex-start; }
body.tier-1 .card.w-panel{ flex:none; }
/* 右栏底部加一个"等待解锁"的占位说明（有内容 > 空白） */
```

> 缺点：右侧仍是窄栏，培养皿无法居中，**画框感弱于方案 A**。

### 方案 C（仅视觉兜底，不推荐）—— 给空区加"暗角"

用径向渐变把右栏空区压暗，视觉上"缩窄"页面的内容边界。

```css
body.tier-1 .grid::after{ /* … */ }
```

> **不推荐**：这是"遮盖"而非"设计"，且与培养皿暗角重复。**留白应该是主动设计的，不是被动遮的** —— 用户要的是"高级"，不是"看不见"。

### 通用：内容少时的三条原则

1. **居中 > 左对齐铺满** —— 内容少时，居中版心天然产生"画框"感。
2. **并排 > 上下堆叠** —— 两个短块并排比一上一下更"完整"。
3. **对齐 > 填充** —— 宁可底部留白，不要拉伸元素填满（拉伸会产生"变形感"）。
